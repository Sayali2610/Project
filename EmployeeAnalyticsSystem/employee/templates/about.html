Project Information

The Employee Analytics System is designed to manage employee information efficiently. It reads employee data from a CSV file using Pandas, performs statistical analysis using NumPy, and displays the results through a Django web application. Users can browse employee records, search employees by Employee ID or Name, and view salary statistics such as average salary, highest salary, and lowest salary. This project demonstrates practical implementation of Python for Data Analysis and Web Development.
